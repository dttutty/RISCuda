# LLM 集成：一次主机执行图启动

[English](qwen-python.md) | **简体中文** · [返回首页](../../README.zh-CN.md) · [验证索引](../../VALIDATION.zh-CN.md)

RISC-V/Python 执行层还在配套模型集成中验证：使用真实 Qwen3.8-27B INT8 权重、
greedy 解码并关闭 thinking。CPU 准备模型权重、缓存、解释器 RAM 和已捕获执行图，
随后启动一个根 CUDA Graph。该执行图完成实际提示词预填充、token 生成、Python 工具检测、
RISC-V 执行、整数结果 token 构造，以及模型继续生成直到 EOS。

Qwen 生成了一段处理整数 1..137 的 while/if 程序。客户机执行 1,338,921 条指令，
返回 269859，Qwen 在最终答案中使用了该工具结果。请求包含 82 个生成 token、
35 个注入 token 和 117 次解码前向，预填充为 450 个 token，最终缓存位置数为 567。

采样器的请求区间记录如下：

| 观察项 | 数值 |
| --- | --- |
| 主机 CUDA Graph 启动 | **1** |
| 主机 kernel 启动 API 调用 | **0** |
| 主机 memcpy API 调用 | **0** |
| 主机与设备间拷贝活动 | **0** |
| GPU 根执行图执行 | **1** |
| GPU 执行图耗时，包含预填充 | **8.224940565 s** |

CUDA Graph 内包含多个 GPU kernel。测量确认的是一次主机启动，
推理与工具循环并非单个融合 kernel。独立 Python API 则在一个 kernel 中执行完整客户机调用。
整图级跟踪不采集单独的 kernel 执行活动。

[轨迹摘要](../../docs/evidence/qwen_python_single_launch.json)记录了模型版本、生成源码、
数值检查、采样计数和源码哈希。配套实验从包含本地修改的工作区捕获，
其基础提交和非干净工作区状态均有记录。独立解释器镜像是另一次构建，
因此独立 wheel 验证中的 1813 指令字镜像及独立耗时不会代替配套的 1812 指令字运行。
初始化、预热和最终输出收集均位于采样区间之外。
